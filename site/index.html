The short version.

SAH means Service Automation Hub. ComputeAPI handles capacity, SystemAPI handles fleet control, and adssh handles shell execution. The farm tools discover, govern, coordinate, and verify work.

The complete provision → enroll → execute handoff is still in development. You can use the existing tools independently today.

Start with the local index.

git clone https://github.com/afterdarksys/opensah.git
cd opensah
go install ./cmd/opensah
opensah tools

Requires Go 1.26 or later and the Go binary directory on your PATH. See installation for the complete suite.
